## 🇬🇧 English

### What is this?

A beautiful, self-contained **HTML guide** designed specifically for developers who want to feel confident on Linux servers. No fluff — only the commands, concepts, real-world scenarios, common mistakes, and exercises you actually need.

The guide is written in **Persian (Farsi)** with a modern dark theme, sticky table of contents, and clean code blocks.

### Topics Covered

| Section | Lessons |
|---------|---------|
| **Basics & Mindset** | What is Linux, distributions, Kernel vs Shell, first commands |
| **File System** | FHS structure, navigation, `ls`, `cp`, `mv`, `rm`, `find` |
| **Viewing & Editing** | `cat`, `less`, `tail -f`, nano, vim survival kit |
| **Search** | `grep`, `find` + `grep`, `locate` |
| **Users & Permissions** | Users, groups, `sudo`, `chmod`, `chown`, never use 777 |
| **SSH & Security** | Key-based auth, `scp`, `rsync`, hardening `sshd_config` |
| **Processes & Resources** | `ps`, `top`, `htop`, `kill`, `tmux`, `free`, `df`, `du`, `lsof` |
| **Packages & Services** | `apt`, `systemctl`, writing your own unit files |
| **Networking** | Ports, `curl`, `ss`, `ufw`, DNS |
| **Bash Scripting** | Scripts, conditionals, loops, functions, `sed`, `awk`, `xargs` |
| **Daily Developer Tasks** | `cron`, logs, Git on server, deploying Node.js + Nginx + SSL |
| **Troubleshooting & Security** | Systematic debugging, firewall, fail2ban, best practices |
| **Cheat Sheets** | 25 essential commands + 50-command checklist |

### How to Use

1. **Just open it**  
   Download or clone the repo and open `index.html` in any modern browser.

2. **Visit Online**  
   visit [linux-guide-for-developers](https://madifrontend.github.io/linux-guide-for-developers/)

### Features

- Fully offline (single HTML file)
- Beautiful dark theme with syntax highlighting
- Sticky RTL table of contents
- Real-world scenarios + common mistakes + exercises
- Mobile responsive
- Zero dependencies
